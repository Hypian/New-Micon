# Micon Real Line — Website

Rwanda's premier advertising and technology company website. Smart LED street advertising platform.

## 📁 Project Structure

```
├── src/                          # Frontend source files
│   ├── index.html               # Main HTML
│   ├── styles.css               # Global styles with design tokens
│   ├── main.js                  # Core JavaScript (interactivity, animations)
│   └── assets/                  # Media & resources
│       └── logos/               # Brand logos
│
├── scripts/                     # Build & utility scripts
│   └── build.py                 # Consolidated build utilities
│
├── .agents/                     # AI agent customization
│   └── skills/                  # Design system skills (Tailwind, Frontend Design)
│
├── .vscode/                     # Editor configuration
├── .github/                     # GitHub workflows
└── README.md                    # This file

## 🚀 Quick Start

1. Open `src/index.html` in your browser
2. All styles are in `src/styles.css`
3. JavaScript interactivity in `src/main.js`

## 🎨 Design System

- **Colors**: Purple (#6B21A8), Orange (#F97316), Pink (#EC1E6B)
- **Font**: Inter (300-800 weights)
- **Design Tokens**: Defined in CSS custom properties
- **Icons**: Boxicons + Lucide

## 📝 Features

- ✨ Floating glass navigation menu
- 🎬 Hero section with animations
- 📊 Stats section with counters
- 📱 Fully responsive design
- ♿ Semantic HTML & ARIA labels
- 🎯 Form validation

## 🛠 Development

- No build process required — works directly in browser
- Tailwind CSS via CDN
- Custom CSS for brand-specific styling
- Vanilla JavaScript (no frameworks)

## 📦 Skills & Tools

- **Tailwind Design System**: Component patterns and tokens
- **Frontend Design**: Visual design guidance and aesthetics
- **VS Code**: Custom agent configuration for development
